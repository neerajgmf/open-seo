# GoStudio.ai Copywriting Rules

Use alongside `../../gostudio-product-marketing-context/references/product-marketing-context.md`.

## Always Use

- Concrete proof points from `gostudio-product-marketing-context`.
- Identity-preserving language for face/product workflows when the source context supports it.
- "Train once" language only for trained model workflows described in the source context.
- B2B CTA language from the source context for product photography pages.
- Free-tier language only where the source context says it applies.

## Never Use

- Banned words from the product marketing context.
- Roadmap features as live features.
- Generic AI image generator framing without identity/input context.
- Beauty-app framing.
- Unsupported claims like "best," "fastest," or "unlimited" unless the page has proof.

## Rewrite Checklist

- Does the first sentence answer the user's intent?
- Does every claim have a "so what"?
- Is pricing current?
- Is the right part of the studio clear (handpicked AI models vs one-click AI tools)?
- Is the CTA correct for the page type?
- Is the copy short enough for the component?
