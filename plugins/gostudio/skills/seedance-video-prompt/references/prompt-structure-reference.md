# Seedance 2.0 — Prompt Structure Quick Reference

## The Formula (copy-paste template)

```
[SUBJECT: who/what — key visual details],
[ACTION: what they do — progressive verb, speed, body language],
in [ENVIRONMENT: where — indoor/outdoor, time, weather, depth cues],
camera [MOVEMENT: one type only — direction, speed],
style [STYLE: aesthetic — lighting, color, texture, mood],
avoid [CONSTRAINTS: what to exclude]
```

## Reference Assignment Template

```
@Image1 as [role: first frame | character | environment | style]
@Image2 as [role]
@Video1 for [role: camera movement | action | edit source]
@Audio1 as [role: BGM | voice | SFX]
```

## Time-Segment Template

```
【Style】[aesthetic keywords]
【Duration】[N seconds]

[00:00–00:XX] Shot name (camera type).
[Visual description]
[Action description]
[Audio cue]

[00:XX–00:YY] Shot name (camera type).
...
```

## Camera Movement Cheat Sheet

| Movement | Trigger phrase |
|---|---|
| Push-in | `camera slowly pushes in` |
| Pull-out | `camera pulls out to reveal` |
| Pan L/R | `camera pans [left/right] across` |
| Tilt U/D | `camera tilts [up/down] from` |
| Tracking | `camera tracks alongside` |
| Orbit | `camera orbits around` |
| Aerial | `aerial camera descends toward` |
| Handheld | `subtle handheld camera` |
| Fixed | `fixed camera, no movement` |
| Crane | `crane shot rising above` |
| Whip pan | `whip pan to the [direction]` |
| Hitchcock | `dolly out while zooming in` |
| POV | `first-person POV` |

## Lighting Keywords (highest impact on output)

`golden hour` · `rim light` · `natural light` · `neon` · `backlit` · `overcast` ·
`studio lighting` · `candlelight` · `moonlight` · `fluorescent` · `volumetric light` ·
`dappled sunlight` · `silhouette` · `high key` · `low key`

## Style Anchors

`cinematic` · `film grain` · `4K` · `shallow depth of field` · `anamorphic` ·
`documentary` · `warm tone` · `cool tone` · `moody` · `soft focus` · `lens flare` ·
`desaturated` · `high contrast` · `vintage` · `noir`

## Hard Limits

| Limit | Value |
|---|---|
| Max images | 9 |
| Max videos | 3 |
| Max audio | 3 |
| Max combined | 12 |
| Output duration | 4–15 seconds |
| Output resolution | 480p–720p |
| Optimal word count | 60–100 words (simple prompt) |
| Realistic human faces | NOT supported |
